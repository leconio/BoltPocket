# BoltPocket

[English](README.md) · [完整局限性](docs/LIMITATIONS.md) · [实测口径](docs/BENCHMARKS.md) · [构建说明](docs/BUILD.md)

一个在手机 App 进程内运行 llama.cpp 的实验项目。聊天页面、项目工作区和 Pi 0.83.0 会话/工具逻辑复用自作者的 Wield 代码，采用独立身份 `dev.boltpocket.app`。不依赖 Wield 账号或推理后端，保留 SSH、MCP 和项目工具代码。

目前实测成功的是 **Galaxy S25 / Adreno 830 的 OpenCL 路线**。项目包含针对该设备大词表 Q4_K 投影错误的兼容修改，并支持将固定系统提示和工具定义对应的上下文状态保存在 Android 私有目录，重启后恢复。

## 当前局限性

- 只完成一台 S25、一个历史 GGUF 的真机验证。其他 Android、其他模型和驱动不能据此视为支持；Vulkan 在这台 S25 上失败。
- iOS 有桥接与构建源码，但 iPhone 安装、性能、持久缓存恢复尚未验证。
- 模型体积约 4.43 GiB；长任务观测到应用峰值 PSS 约 6.67 GiB，低内存设备不在验证范围内。尚无长期恒温、功耗和耗电对照。
- 固定前缀缓存不是完整会话缓存：新问题、历史和工具结果仍要处理；模型权重仍需加载。缓存不保证永远命中，配置、前缀或系统变化可能使它失效。
- 缓存约占 406 MiB 磁盘，最多保留两份、每份上限 512 MiB。卸载或清除 App 数据会删除它。App 对话历史的持久化是另一套机制。
- 当前为 16K 上下文、每次模型调用最多输出 256 token、Thinking Off。长回答或工具参数可能被截断；“思考”区域显示执行进度，不代表模型推理过程。
- Pi 自动压缩代码保留，但不等于无限上下文，也不保证压缩不丢细节。本次多步录屏没有验证压缩触发后的行为。
- 任务执行完不代表内容全部正确：天气行程测试中，预算 HKD300 校验通过；追加修正后，模型仍把精确观测时间写成 `Obs time noted`，也没有充分区分一般台风资讯与香港警告。
- 复用页面在最终回答完成后才显示整段文本。原生 TTFT、到 JS 的首文本事件和屏幕首字不是同一指标。
- 项目 `bash` 是受限的虚拟项目 Shell。Python/Node 等命令不能当作手机系统上已有的执行环境；SSH/MCP 等需要用户自行配置，联网工具也会联网。
- 源码需要自行构建、签名和导入模型，不能用 Expo Go。没有随库提供权重、系统 OpenCL 驱动、签名凭据或生产 APK。

还有一个重要的复现限制：2026-10-24 核对时，上游同名 GGUF 与实测文件的大小和哈希不同，记录的历史 revision 无法获取。因此不能直接下载“最新版”后声称复现了本仓库的 S25 数字。[模型详情](docs/MODEL.md)。

## 已有数字

| 样本 | 实测 |
|---|---|
| 8K、英文三次重复问题、OpenCL | 生成中位数 **7.10 tok/s** |
| 16K 缓存长任务、12 次模型调用 | 生成中位数 **6.58 tok/s**；任务 **2 分 22 秒**；峰值 PSS **6.67 GiB** |
| 同一个短提示，首次构建/重启恢复 | 原生 TTFT **102.32 s / 8.59 s**；重启后模型加载 **18.11 s** 另计 |

这些样本的上下文、输出和缓存条件不同。旧 CPU 基线使用中文、GPU 使用英文，ubatch 也不同，不能当作严格的同条件加速比。

## 使用

按照 [构建说明](docs/BUILD.md) 在 Linux/WSL 编译 Android 原生模块和 App。项目默认英文，导入模型前先阅读 [模型指纹与许可](docs/MODEL.md)。详细实验条件、数据和验收失败项在 [BENCHMARKS.md](docs/BENCHMARKS.md)。
